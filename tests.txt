Лабораторная работа № 1. Набор тестов приложения mathtool
Файл tests.txt. Лимит коэффициентов: 10000.

ПОРЯДОК ПРОВЕРКИ
1. Открыть в VS Code папку, содержащую mathtool.py.
2. Выполнить указанную команду в терминале PowerShell.
3. Для ручного ввода вводить каждое значение на отдельной строке.
   Обозначение <пустая строка> означает нажатие Enter без текста.
4. Сравнить результат с ожидаемым. Приглашения ввода не являются строками ответа.
5. Сразу после запуска выполнить $LASTEXITCODE для проверки кода возврата.
6. Сообщения об ошибках должны идти в stderr, решения и справка — в stdout.
   Для раздельной проверки потоков дописать к команде:
       1> result.txt 2> error.txt
   При ошибке сообщение должно попасть в error.txt, а не в result.txt.
   При ручном вводе приглашения input() относятся к stdout.

ОЖИДАЕМЫЕ РЕЗУЛЬТАТЫ
Результаты ниже заданы по инструкции, а не подогнаны под ошибки текущего кода.
Для ошибок важны смысл сообщения, поток stderr и код 1; формулировка
об ошибке диапазона приведена по образцу инструкции.
Дополнительное пояснение об отсутствии корней допускается, если вид
уравнения, дискриминант и итоговое сообщение указаны верно.
Отсутствие действительных корней — успешный результат, код 0.
